# Unpushed package branches

`local-branches.bundle` holds every local branch of the work repository that the remote does not hold, refreshed at 2026-11-12 23:31 UTC. Restore with `git clone local-branches.bundle` or `git fetch local-branches.bundle 'refs/heads/*:refs/heads/*'` inside a clone of the repository. `local-heads.txt` lists each branch, its commit and date at that time. Each refresh replaces the file; git history keeps the earlier ones.
